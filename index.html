01 · Materi

Kenali konsep komposisi fungsi

Pelajari setiap topik secara berurutan. Gunakan daftar di samping untuk berpindah langsung ke submateri.

Daftar Materi
1. Pengertian2. Notasi3. Langkah hitung4. Sifat5. Tiga fungsi6. Nilai fungsi7. Kontekstual

1. Pengertian komposisi fungsi

Komposisi fungsi adalah operasi yang menggabungkan dua fungsi atau lebih dengan memasukkan keluaran suatu fungsi sebagai masukan fungsi berikutnya. Bayangkan sebuah proses berurutan: masukan melewati mesin pertama, lalu hasilnya diproses oleh mesin kedua.

(f ∘ g)(x) = f(g(x))

Notasi tersebut dibaca “f komposisi g dari x”. Fungsi g bekerja lebih dahulu, kemudian fungsi f memproses hasilnya.

Ingat: pada (f ∘ g)(x), kerjakan fungsi yang berada paling dekat dengan x terlebih dahulu, yaitu g(x).
Lanjut ke notasi →

2. Notasi dan maknanya

Komposisi fungsi dapat ditulis dengan simbol ∘. Jika f(x) = 2x + 1 dan g(x) = x², maka:

(f ∘ g)(x) = f(g(x)) = 2x² + 1

Sebaliknya, (g ∘ f)(x) berarti g(f(x)), sehingga hasil fungsi f dimasukkan ke fungsi g.

(g ∘ f)(x) = g(2x + 1) = (2x + 1)²

Kedua hasil tersebut berbeda. Karena itu, perhatikan urutan fungsi sebelum melakukan substitusi.

Lanjut ke langkah hitung →

3. Langkah menentukan komposisi dua fungsi

  1. Tulis fungsi yang diminta, misalnya (f ∘ g)(x).
  2. Ubah notasi menjadi f(g(x)).
  3. Ganti setiap x pada fungsi f dengan seluruh bentuk g(x).
  4. Sederhanakan bentuk aljabar dengan teliti.
  5. Periksa kembali tanda kurung dan operasi pangkat.
Contoh singkat

f(x) = 3x − 2 dan g(x) = x + 4. Tentukan (f ∘ g)(x).

(f ∘ g)(x) = f(x + 4)

= 3(x + 4) − 2

= 3x + 12 − 2

= 3x + 10

Lanjut ke sifat →

4. Sifat-sifat komposisi fungsi

Komposisi fungsi bersifat asosiatif apabila fungsi-fungsi terkait terdefinisi, sehingga pengelompokan dapat berubah tanpa mengubah urutan fungsi.

f ∘ (g ∘ h) = (f ∘ g) ∘ h

Namun, komposisi fungsi pada umumnya tidak komutatif. Artinya, menukar urutan fungsi biasanya menghasilkan keluaran berbeda.

f ∘ g ≠ g ∘ f (pada umumnya)
Jangan menyimpulkan bahwa kedua komposisi selalu berbeda. Pada fungsi tertentu, hasilnya bisa saja sama.
Lanjut ke tiga fungsi →

5. Komposisi tiga fungsi

Untuk tiga fungsi, prosesnya tetap berurutan. Pada (f ∘ g ∘ h)(x), fungsi h bekerja lebih dahulu, disusul g, lalu f.

(f ∘ g ∘ h)(x) = f(g(h(x)))
Contoh

f(x) = x + 1, g(x) = 2x, dan h(x) = x². Tentukan (f ∘ g ∘ h)(x).

h(x) = x²

g(h(x)) = g(x²) = 2x²

f(g(h(x))) = f(2x²) = 2x² + 1

Jadi, (f ∘ g ∘ h)(x) = 2x² + 1.

Lanjut ke nilai fungsi →

6. Menentukan nilai komposisi fungsi

Jika soal meminta nilai komposisi pada angka tertentu, tentukan bentuk komposisinya atau hitung bertahap dengan memasukkan nilai ke fungsi paling dalam terlebih dahulu.

Contoh

f(x) = 2x + 3 dan g(x) = x² − 1. Tentukan (f ∘ g)(2).

g(2) = 2² − 1 = 3

f(g(2)) = f(3) = 2(3) + 3 = 9

Jadi, (f ∘ g)(2) = 9.

Lanjut ke penerapan →

7. Penerapan dalam kehidupan sehari-hari

Komposisi fungsi dapat menggambarkan proses yang berlangsung bertahap. Misalnya, sebuah toko memberikan diskon terlebih dahulu, lalu menghitung biaya tambahan berdasarkan harga setelah diskon.

Ilustrasi

Harga awal barang adalah x rupiah. Fungsi diskon 10% adalah d(x) = 0,9x. Setelah diskon, toko menambahkan biaya layanan tetap Rp5.000 dengan fungsi b(x) = x + 5.000.

(b ∘ d)(x) = b(0,9x) = 0,9x + 5.000

Model ini menunjukkan bahwa biaya akhir bergantung pada hasil proses diskon terlebih dahulu.

02 · Contoh soal

Lihat prosesnya, pahami alasannya

Gunakan pembahasan ini sebagai model untuk menyelesaikan soal serupa secara mandiri.

Contoh 1 · Komposisi dua fungsi

Diketahui f(x) = 2x + 3 dan g(x) = x² − 1. Tentukan (f ∘ g)(x).

  1. Gunakan definisi: (f ∘ g)(x) = f(g(x)).
  2. Substitusikan g(x) = x² − 1 ke dalam f.
  3. f(x² − 1) = 2(x² − 1) + 3.
  4. = 2x² − 2 + 3.
(f ∘ g)(x) = 2x² + 1

Contoh 2 · Urutan dibalik

Dengan fungsi yang sama, tentukan (g ∘ f)(x).

  1. (g ∘ f)(x) = g(f(x)).
  2. Masukkan f(x) = 2x + 3 ke fungsi g.
  3. g(2x + 3) = (2x + 3)² − 1.
  4. = 4x² + 12x + 9 − 1.
(g ∘ f)(x) = 4x² + 12x + 8

Perhatikan bahwa hasilnya tidak sama dengan (f ∘ g)(x). Perbedaan muncul karena urutan substitusi berubah.

Contoh 3 · Menentukan nilai komposisi

Diketahui f(x) = x − 5 dan g(x) = 3x + 2. Tentukan (f ∘ g)(4).

  1. Hitung g(4) = 3(4) + 2 = 14.
  2. Masukkan hasil tersebut ke f: f(14) = 14 − 5 = 9.
(f ∘ g)(4) = 9

Contoh 4 · Komposisi tiga fungsi

Diketahui f(x) = x + 2, g(x) = x², dan h(x) = 2x. Tentukan (f ∘ g ∘ h)(x).

  1. h(x) = 2x.
  2. g(h(x)) = (2x)² = 4x².
  3. f(4x²) = 4x² + 2.
(f ∘ g ∘ h)(x) = 4x² + 2

Contoh 5 · Menentukan fungsi dari konteks

Sebuah bilangan x dikalikan 5, kemudian dikurangi 4. Jika f(x) = 5x dan g(x) = x − 4, nyatakan proses tersebut sebagai komposisi.

Perkalian terjadi lebih dahulu, sehingga prosesnya adalah g(f(x)).

(g ∘ f)(x) = g(5x) = 5x − 4

06 · Ringkasan

Rumus penting dalam satu tempat

Gunakan bagian ini untuk mengulang konsep sebelum mengikuti tes akhir.

ƒ

Definisi utama

(f ∘ g)(x) = f(g(x))

Fungsi g bekerja terlebih dahulu, kemudian hasilnya menjadi masukan fungsi f.

↔

Urutan fungsi

(g ∘ f)(x) = g(f(x))

Jika urutan dibalik, proses dan hasilnya dapat berubah.

③

Tiga fungsi

(f ∘ g ∘ h)(x) = f(g(h(x)))

Kerjakan dari fungsi paling dalam, yaitu h, lalu g, kemudian f.

✓

Hindari kesalahan umum

Jangan menukar urutan fungsi, jangan lupa tanda kurung saat substitusi, dan sederhanakan aljabar secara bertahap.
